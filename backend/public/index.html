Goal Tracker API

Version: v1

Base path: /api/v1

Auth: accessToken cookie or Authorization Bearer token

Routes

Method Path Auth Notes
GET /api/v1/healthcheck No Health check
POST /api/v1/user/register No Creates user and sets accessToken cookie
POST /api/v1/user/login No Logs in and sets accessToken cookie
POST /api/v1/user/logout Yes Clears accessToken cookie
GET /api/v1/user/me Yes Current user profile
GET /api/v1/user/all-users Admin RBAC protected
GET /api/v1/goals Yes List user goals
POST /api/v1/goals Yes Create goal
PUT /api/v1/goals/:id Yes Update goal title
DELETE /api/v1/goals/:id Yes Delete goal

Response Shape

Success: success, statusCode, message, data

Error: statusCode, message, errors, success

Validation errors return 422 with field-level errors.
